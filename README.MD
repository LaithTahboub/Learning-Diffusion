# Diffusion Learning
## DDPM from Scratch

<img width="530" height="266" alt="generated_3" src="https://github.com/user-attachments/assets/e7015688-becf-43a6-b0a6-7642b59c970e" />

Implemented the DDPM as introduced by Ho et al. The architecture includes the DDPM forward and reverse processes and a UNet as the base model for predicting noise. The model was trained on a dataset of ~4,000 images using an RTX A6000 GPU.
